# 고객 노트 — J Harness 로컬 개발 데모

고객 추가·목록·검색·수정·삭제와 이메일 검증을 제공하는 작은 웹 앱입니다. Node.js 22 이상만 필요하며 npm 패키지 설치나 외부 서비스가 없습니다.

1. 이 폴더에서 `node server.mjs`를 실행합니다.
2. 브라우저에서 http://127.0.0.1:3848 을 엽니다.
3. 이름·이메일·메모를 입력해 저장하고, 검색·수정·삭제를 사용합니다. 합성 데이터로 체험하세요.
4. 종료는 서버 터미널에서 Ctrl+C입니다. 다시 실행하면 `data/customers.json`의 자료를 읽습니다.

검증은 `node --test app.test.mjs`입니다. 테스트 데이터는 별도 임시 폴더를 사용하므로 데모의 저장 파일을 변경하지 않습니다. 포트가 사용 중이면 PowerShell에서 `$env:PORT='3849'; node server.mjs`로 다른 포트를 지정합니다.

현재 데모는 한 PC의 로컬 MVP입니다. 공개 인터넷에 노출하지 마세요. 다중 사용자 인증, 권한, HTTPS, 백업, 동시 프로세스 저장 충돌 제어는 공개 운영 전에 구현해야 합니다. API 자동 검증과 브라우저 조작 검증은 별개이며, 실행하지 않은 브라우저 검증은 NOT_RUN입니다.
