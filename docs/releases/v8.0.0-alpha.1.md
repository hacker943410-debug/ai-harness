# J Harness v8.0.0-alpha.1 — Windows CLI 배포 후보

**채널:** Pre-release / 서명되지 않은 개발 후보 / 보안 강제 기능 미통합.

## PowerShell에서 설치 (별도 Node·Git·gh CLI 설치 불필요)

다음 명령은 Windows PowerShell에서 실행합니다. 다운로드한 스크립트를 먼저 확인하고, 설치 전 `INSTALL`을 직접 입력해야 합니다.

```powershell
$u = 'https://raw.githubusercontent.com/hacker943410-debug/ai-harness/feature/v8-integrated-installer-first-use/scripts/Install-JHarnessFromGitHub.ps1'
Invoke-WebRequest -Uri $u -OutFile .\JHarness-Install-Alpha.ps1
Get-Content .\JHarness-Install-Alpha.ps1
powershell.exe -NoProfile -File .\JHarness-Install-Alpha.ps1 -Action Plan
powershell.exe -NoProfile -File .\JHarness-Install-Alpha.ps1 -Action Install
```

소스는 기존 CI 검증 커밋 `a4f8e258d729f302e701d00a52610b778821fcaf`으로 고정됩니다. 공식 Node.js 22.22.2의 SHA-256을 확인하며, 기존 Codex가 없으면 공식 Codex CLI 0.166.0을 내려받아 해시 검증합니다. Codex 추가 다운로드량은 약 372 MB입니다. 현재 지원 플랫폼은 **Windows x64**입니다.

설치 후:

```powershell
& "$env:LOCALAPPDATA\JHarness-Bootstrap\J_Harness_Doctor.cmd"
& "$env:LOCALAPPDATA\JHarness-Bootstrap\J_Harness_Start.cmd"
& "$env:LOCALAPPDATA\JHarness-Bootstrap\J_Harness_Remove.cmd"
```

설치 파일만 만들려면 `-Action Package -Destination "$env:USERPROFILE\Downloads\JHarnessAlpha"`를 사용합니다. 기존 같은 이름의 폴더는 덮어쓰지 않습니다.

## 릴리스 범위 및 제한

- 기존 Codex 인증·설정·프로젝트와 영구 PATH를 변경하지 않는 설치를 목표로 하며, 임시 Windows CI에서 설치/제거/재설치/원본 SHA 복원을 검증했습니다.
- 위 설치 스크립트는 현재 **개발 브랜치에서 제공**됩니다. 독립적으로 서명된 정식 배포 채널이나 GitHub Releases의 첨부파일이 아닙니다.
- 모델 로그인 및 실제 AI 개발 작업, Claude/AGY 호환, 안전한 자동 업그레이드, 사용자 전용 ON/OFF, Supervisor OS 수준 명령 통제는 아직 미검증/미통합입니다.
- 공식 GitHub Pre-release를 게시하려면 소유자가 배포 후보와 해시를 별도로 승인하고 GitHub Releases에 게시해야 합니다. `main`과 운영 제품은 변경하지 않습니다.
- **NO-GO for stable/production.** Windows 테스트 PC에서만 검증용으로 사용하십시오.
