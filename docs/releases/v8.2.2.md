# J Harness 8.2.2 Windows x64

프로젝트에 저장한 AI를 `environment inspect`와 `environment plan`에서 기본으로 검사합니다. 이번에만 다른 AI를 확인하려면 `--client claude`처럼 지정하세요.

Windows x64, Windows PowerShell 5.1 이상에서 실행합니다. ZIP에는 Core, Node 22.23.5, 공통 정책과 Skills가 들어 있습니다.

## 새 프로젝트 설치

8.2.2 설치기를 다운로드하고 설치하려는 프로젝트 경로를 지정합니다.

```powershell
$u = 'https://raw.githubusercontent.com/hacker943410-debug/ai-harness/refs/tags/v8.2.2/scripts/Install-JHarnessFromGitHub.ps1'
Invoke-WebRequest -Uri $u -OutFile .\JHarness-Install.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\JHarness-Install.ps1 -Action Plan -ProjectPath 'C:\Projects\MyProject'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\JHarness-Install.ps1 -Action Install -ApproveInstall -ProjectPath 'C:\Projects\MyProject'
```

프로젝트 폴더에서 `.\JHarness.cmd quickstart`를 실행하고 Codex, Claude Code, AGY 중 사용할 CLI를 고릅니다.

## 기존 프로젝트 업데이트

CLI 세션을 닫고 진행 중인 작업을 마친 뒤 같은 8.2.2 설치기를 사용합니다. Alpha 3, 8.1.0, 8.2.0, 8.2.1의 지원 배포본에서 업데이트할 수 있습니다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\JHarness-Install.ps1 -Action Plan -Upgrade -ProjectPath 'C:\Projects\MyProject'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\JHarness-Install.ps1 -Action Install -Upgrade -ApproveInstall -ProjectPath 'C:\Projects\MyProject'
```

계획 단계는 해시를 확인한 ZIP으로 변경 사항을 조회하고 프로젝트 파일을 보존합니다. 설치 단계는 기존 하네스 파일을 백업하고 업데이트합니다. 중단 상태를 복구할 때는 업데이트를 시작한 것과 같은 버전의 설치기, 같은 프로젝트 경로를 사용합니다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\JHarness-Install.ps1 -Action Recover -Upgrade -ApproveInstall -ProjectPath 'C:\Projects\MyProject'
```

실행 정책 옵션은 해당 PowerShell 프로세스에만 적용됩니다. 네트워크 없이 설치하거나 업데이트하려면 [이동형 ZIP 안내](../../core/portable/PORTABLE.md)를 따르세요.

## 검증 범위

- 로컬 회귀 테스트 53건 통과, 실패 0건, Windows 링크 생성 제약으로 3건 건너뜀.
- 검증한 ZIP으로 Windows PowerShell 5.1 새 설치, Alpha 3와 8.2.1 업그레이드를 실행했습니다. 8.2.1에서 기존 AI 선택과 사용자 파일이 유지됐습니다.
- 잘못된 ZIP 해시는 차단됐고, 업데이트 계획은 대상 프로젝트를 변경하지 않았습니다. 테스트 프로젝트에서 중단을 모의해 8.2.1 복구 후 다시 업데이트했습니다.
- 별도 물리 PC와 Claude Code·AGY의 실제 모델 응답은 이번 검증 범위에 포함하지 않았습니다.
