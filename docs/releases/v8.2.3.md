# J Harness 8.2.3 Windows x64

새 CLI 세션에서 첫 일반 요청을 보내면 AI가 `badge`로 설치 상태와 프로젝트 연결을 확인합니다. 확인한 뒤에는 각 차례의 진행 메시지나 답변 첫 줄에 `[J Harness v8.2.3]`을 한 번 표시합니다. 도구를 사용할 수 없으면 `[J Harness v8.2.3 · 지침 로드]`를 표시합니다. JSON처럼 출력 형식을 지정한 경우에는 별도의 진행 메시지를 사용할 수 있을 때 표시합니다.

Windows x64와 Windows PowerShell 5.1 이상에서 실행합니다. ZIP에는 Core, Node 22.23.5, 공통 정책과 Skills가 들어 있습니다.

## 새 프로젝트 설치

8.2.3 설치기를 다운로드하고 프로젝트 경로를 지정합니다.

```powershell
$u = 'https://raw.githubusercontent.com/hacker943410-debug/ai-harness/refs/tags/v8.2.3/scripts/Install-JHarnessFromGitHub.ps1'
Invoke-WebRequest -Uri $u -OutFile .\JHarness-Install.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\JHarness-Install.ps1 -Action Plan -ProjectPath 'C:\Projects\MyProject'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\JHarness-Install.ps1 -Action Install -ApproveInstall -ProjectPath 'C:\Projects\MyProject'
```

프로젝트 폴더에서 `.\JHarness.cmd quickstart`를 실행하고 Codex, Claude Code, AGY 중 사용할 CLI를 하나 고릅니다. 선택한 CLI를 같은 폴더에서 새로 열고 첫 개발 요청을 입력합니다.

## 기존 프로젝트 업데이트

진행 중인 작업을 마치고 CLI 세션을 닫은 뒤 같은 8.2.3 설치기를 사용합니다. 지원하는 이동형 배포본은 Alpha 3, 8.1.0, 8.2.0, 8.2.1, 8.2.2입니다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\JHarness-Install.ps1 -Action Plan -Upgrade -ProjectPath 'C:\Projects\MyProject'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\JHarness-Install.ps1 -Action Install -Upgrade -ApproveInstall -ProjectPath 'C:\Projects\MyProject'
```

설치기는 ZIP의 고정 SHA-256을 확인합니다. 업데이트는 기존 하네스 파일을 백업합니다. 중단 후 복구하려면 업데이트를 시작할 때 사용한 설치기와 프로젝트 경로로 아래 명령을 실행합니다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\JHarness-Install.ps1 -Action Recover -Upgrade -ApproveInstall -ProjectPath 'C:\Projects\MyProject'
```

네트워크 없이 설치하거나 업데이트하려면 [이동형 ZIP 안내](../../core/portable/PORTABLE.md)를 따릅니다.

## 검증 범위

- 로컬 자동화 테스트 53건 통과, 실패 0건, 3건 건너뜀.
- 검증한 ZIP으로 Windows PowerShell 5.1의 새 설치, Alpha 3와 8.2.2 업데이트, 중단을 모의한 뒤 8.2.2 복구를 확인했습니다. 기존 AI 선택과 사용자 파일도 유지됐습니다.
- 실제 Codex가 프로젝트 연결 확인 뒤 버전을 한 번 표시했습니다. 실제 AGY는 도구를 사용할 수 없는 세션에서 일반 요청 두 차례에 지침 로드 표시를 했고, JSON 전용 요청의 원문을 보존했습니다.
- Claude Code는 로컬 모의 환경에서 지침 전달을 검증했습니다. Claude 모델 응답과 별도 물리 PC 설치는 실행하지 않았습니다.
