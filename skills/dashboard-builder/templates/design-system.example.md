# Project Design System Example

## Tone
- Enterprise operations dashboard
- Dense but calm
- Fast scanning over decorative visuals

## Layout
- Max content width: fluid
- 12-column grid
- KPI cards: 4~6 across on desktop
- Primary chart: 8 columns
- Secondary chart: 4 columns

## Components
Header, Filter bar, KPI card, Chart card, Status badge, Data table, Empty/error/loading state.

## Typography
Define project fonts or inherit existing application typography.

## Colors
Use project brand tokens if available. Define semantic tokens rather than hardcoded meaning:
- surface
- text-primary
- text-secondary
- border
- accent
- success
- warning
- danger

## Charts
Keep series palette small and consistent. Prefer direct labels/tooltip clarity over visual effects.
